컷뷰 - 만화책 뷰어 개인정보처리방침
시행일: 2026년 11월 9일

컷뷰는 사용자가 선택한 이미지 폴더와 ZIP·CBZ 파일을 읽는 로컬 뷰어입니다. 계정 가입과 분석 서버를 사용하지 않습니다. iOS·Android 무료 버전에는 Google 광고가 표시됩니다(아래 '광고' 참조). 앱에서 만화 파일이나 읽기 기록을 개발자 서버로 전송하지 않습니다.

광고
iOS·Android 버전은 서재와 책 목록 하단에 배너 광고를 표시합니다. 책을 읽는 동안에는 광고가 나오지 않습니다. Windows·macOS 버전에는 광고가 없습니다.

광고는 Google AdMob이 제공합니다. Google은 광고 게재·측정·부정 사용 방지를 위해 IP 주소, 기기·앱 정보, 광고 상호작용 같은 정보를 수집하고 쿠키나 유사 식별자를 사용할 수 있습니다. 컷뷰는 비개인화 광고만 요청하며 다른 회사의 앱을 넘나드는 추적 권한을 요청하지 않습니다. 만화 파일, 파일 이름, 서재, 읽기 기록은 광고 요청에 포함되지 않습니다.

법에서 요구하는 지역에서는 광고를 표시하기 전에 선택을 묻습니다. 설정 > 정보 > 광고 개인정보 설정에서 나중에 바꿀 수 있습니다. 동의하지 않아도 법이 요구하는 범위에서 앱은 광고 없이 그대로 동작합니다.

Google의 처리 방식은 https://policies.google.com/technologies/partner-sites 에서 확인할 수 있습니다.

광고 제거
App Store 또는 Google Play에서 한 번 구매해 광고를 없앨 수 있습니다. 결제는 Apple 또는 Google이 처리합니다. 앱은 광고 제거 여부만 기기에 저장하며 구매 정보를 개발자 서버로 보내지 않습니다. 컷뷰가 App Store에서 유료 앱이었을 때 구매했다면 광고가 표시되지 않습니다. 이를 확인하기 위해 앱은 App Store의 최초 구매일을 기기에서 읽고 결과를 기기에 저장합니다.

기기에 보관하는 정보
서재 목록과 파일 접근 권한, 읽던 위치, 책별 보정값, 앱 설정, 썸네일 캐시를 기기에 저장합니다. 오류 조사에 필요한 진단 로그도 기기 내부에 기록합니다. 앱 평가 요청을 너무 자주 띄우지 않도록 설치 시각, 완료한 책의 내부 식별자, 가치 행동 횟수, 평가 API 요청 횟수·시각을 로컬에 보관합니다. 수신한 앱 링크는 안전한 화면에서 열 때까지 기기에 보관할 수 있으며 개발자 서버로 보내지 않습니다. 원본 만화 파일은 읽기만 하며 수정하지 않습니다.

정보 삭제
설정의 데이터 메뉴에서 캐시와 읽기 기록을 삭제할 수 있습니다. 서재에서 소스를 제거하면 서재 목록과 연결된 읽기 기록·책별 설정을 삭제합니다. 썸네일 캐시는 별도로 비울 수 있으며, 기기 내부 진단 로그는 즉시 삭제되지 않습니다. 평가 요청 이력과 대기 중 링크는 앱 데이터와 함께 보관됩니다. 운영체제 설정에서 앱 데이터를 지우거나 앱을 삭제하면 운영체제 정책에 따라 제거됩니다. 앱 데이터 삭제는 원본 만화 파일을 삭제하지 않습니다.

운영체제와 외부 서비스
파일 선택기에서 사용자가 선택한 클라우드 파일은 운영체제나 해당 파일 제공업체가 처리할 수 있습니다. Apple·Google의 앱 구매, 스토어 평가, TestFlight·시스템 진단 및 운영체제 백업에는 해당 제공자의 정책과 사용자 설정이 적용됩니다. 앱 평가하기나 다른 앱을 누르면 외부 스토어 앱이 열립니다. 다른 앱 목록과 아이콘은 앱에 포함되며 원격으로 받지 않습니다.

사용자가 직접 공유하는 자료
문제 해결을 위해 사용자가 이메일로 직접 전달하는 문의 내용과 회신 주소는 문의 처리에 사용합니다. 별도로 전달하는 화면이나 진단 자료에는 파일명이 포함될 수 있습니다. 공유 전 내용을 확인해 주세요. 이는 앱이 자동으로 전송하는 정보가 아닙니다.
문의 자료의 삭제를 원하면 아래 연락처로 요청할 수 있습니다. 법적으로 보존할 의무가 있는 경우를 제외하고, 문의 처리에 더 이상 필요하지 않은 자료는 삭제합니다.
