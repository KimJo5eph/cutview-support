자주 묻는 질문

책을 어떻게 추가하나요?

서재에서 폴더 추가 또는 ZIP 추가를 선택하고 시스템 파일 선택기에서 이미지 폴더나 ZIP·CBZ 파일을 선택하세요. 컷뷰는 만화 파일을 제공하지 않습니다. 이용할 권한이 있는 파일만 추가해 주세요.

ZIP 안에 폴더가 여러 개 있어요.

이미지가 담긴 하위 폴더를 각각 별도의 책처럼 열 수 있습니다. 각 책의 읽던 위치가 따로 저장됩니다.

파일을 열 수 없거나 다시 권한을 요청해요.

원본 파일을 옮기거나 이름을 바꾸면 기존 접근 권한을 사용할 수 없을 수 있습니다. 파일이 있는지 확인하고 다시 선택해 주세요. 클라우드 파일은 파일 앱이나 Finder에서 먼저 다운로드한 뒤 다시 열어보세요.

앱이 예기치 않게 종료돼요.

앱을 다시 실행하고 다른 작은 이미지 폴더 또는 ZIP으로도 같은 문제가 생기는지 확인해 주세요. 반복되면 기기·OS·앱 버전, 파일 형식과 크기, 종료 직전에 한 동작을 이메일로 알려주세요. 진단 자료를 전달할 때에는 파일명이나 개인 정보가 포함되었는지 먼저 확인해 주세요.

E-Ink 모드인데 주변 배경은 검정색이에요.

E-Ink 보정은 페이지 내용에 적용합니다. 독서 화면의 주변 배경은 검정색으로 유지되는 것이 정상입니다.

읽기 기록이나 캐시를 삭제하고 싶어요.

설정의 데이터 메뉴에서 읽기 기록이나 캐시를 삭제할 수 있습니다. 서재에서 소스를 제거해도 원본 만화 파일은 삭제되지 않습니다. 내부 진단 로그는 해당 작업으로 즉시 삭제되지 않습니다.

구매·환불은 어떻게 하나요?

App Store 구매 내역과 환불 요청은 Apple에서 관리합니다. Apple 문제 신고 페이지에서 구매 항목을 확인해 주세요. 컷뷰에는 별도 계정이나 인앱 구독이 없습니다.
